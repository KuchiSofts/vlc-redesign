## Download and install

All files are on the **[Releases](https://github.com/KuchiSofts/vlc-redesign/releases/latest)** page, with their
SHA-256 checksums in `SHA256SUMS.txt`. The full guide is
[Install and Update](https://github.com/KuchiSofts/vlc-redesign/wiki/Install-and-Update) on the wiki.

| Platform | What to download |
|---|---|
| **Windows 10 / 11** (64-bit) | The **installer** (recommended: no administrator rights needed, updates itself) or the **portable zip** (unzip and run `vlc.exe`). Both keep their settings in their own `portable` folder, separate from an official VLC installation. |
| **Windows 11 on ARM64** (Snapdragon PCs) | The same two packages, built natively for ARM64. Available since 0.4.1, with in-app updates since 0.5.0. [Details](https://github.com/KuchiSofts/vlc-redesign/wiki/Install-and-Update#windows-on-arm64) |
| **Linux** x86_64 / ARM64 (glibc 2.38: Ubuntu 24.04+, Debian 13, Fedora 39+) | A .deb, .rpm, AppImage or tarball. It installs to `/opt/vlc-redesign` as `vlc-redesign`, next to your distribution's `vlc`. Live TV is an optional add-on package (.deb and .rpm). A Flatpak bundle is also attached to the release. [Which file to pick](https://github.com/KuchiSofts/vlc-redesign/wiki/Install-and-Update#linux) |
| **macOS 12+** (Apple Silicon / Intel) | Drag VLC Redesign to Applications. The app is signed ad hoc, not by Apple, so open it once via *System Settings › Privacy & Security › Open Anyway*. [Details](https://github.com/KuchiSofts/vlc-redesign/wiki/Install-and-Update#macos) |
| **Android 8.0+** (phones and tablets) | The **APK** (`vlc-redesign-0.5.1-android.apk`). Open it on the device and allow installs from that app once. It installs alongside VLC as *VLC Media Player Redesign*. Not available on Google Play. [Details](https://github.com/KuchiSofts/vlc-redesign/wiki/Install-and-Update#android) |

> [!NOTE]
> The Windows files are not code-signed yet (the SignPath application is still pending), so SmartScreen may warn
> on first launch: choose *More info → Run anyway*. The app only installs updates whose file list is signed by the
> project. See [CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md).

The installer follows the app's design and is available in 29 languages (it defaults to the Windows display
language when it has it). It asks for:

- **Languages:** the interface language (any of the 72, or English) and your default subtitle language.
- **Options:** file associations for videos, music and playlists, *Play with VLC Redesign* in the context menu, a
  desktop shortcut, or an install for all users.
- **Privacy:** the update check and online subtitles, each with a note on what it sends and to whom.

Silent installs accept switches such as `/VERYSILENT /UILANG=en /SUBLANG=en /NOUPDATECHECK`. The full list is in
the [wiki](https://github.com/KuchiSofts/vlc-redesign/wiki/Install-and-Update#silent-install).

</details>

<details>
<summary><b>Updates</b></summary>
<br>

On Windows (x64 and ARM64), VLC Redesign checks this repository for a new release once a day
(*Settings → General → Check for updates automatically*, or *⋯ → About → Check for updates*). When one is
available, a card offers **Update now**:

- **A small update** (installed or portable copy) downloads only the files that changed, usually a few megabytes.
  Each file is checked against the release's `SHA256SUMS.txt`, whose signature by the project's release key is
  verified first. **Restart now** applies it in about two seconds and reopens what was playing; **Later** applies it
  when you close VLC Redesign. If anything fails, every file is restored.
- **The full installer** is used when no small update applies (more than three releases behind, or installed for
  all users). It is downloaded, verified and run without prompts.

Linux and macOS have no in-app updates yet: install the new package or disk image.

</details>

<details>
<summary><b>Known limitations</b></summary>
<br>

- **Based on VLC 4.0-dev**, not the stable VLC 3. Expect the occasional rough edge.
- In-app updates are available on Windows only. Windows on ARM64 has not yet been tested by hand on an ARM64 PC,
  and the macOS app is not yet signed by Apple.
- 72 languages cover the whole interface. In VLC's other translation catalogs (listed as partial), only VLC's own
  strings are translated.
- Media Information, Bookmarks, Convert/Stream, Open Media (disc, capture), Messages and the other classic VLC
  windows keep their classic layout, in the redesign's colours and, on Windows, with its title bar and icons.
  *Go to Time*, *Plugins and extensions*, *Media Statistics* and *Folder information* are redrawn as dialogs in the
  new design.
- The waveform seek bar works on local files up to 1 GB and 8 minutes; other media get the regular seek bar.
- HDR output offers Auto / Off / HDR10 / HLG and requires the libplacebo renderer.

</details>

## Building from source

<details>
<summary><b>Build it yourself</b> (Docker, VideoLAN's own build image)</summary>
<br>

The Windows build is a cross-compile in Docker, using VideoLAN's official build image and prebuilt libraries. You
need [Docker Desktop](https://www.docker.com/products/docker-desktop/) and Git.

```powershell
git clone https://github.com/KuchiSofts/vlc-redesign.git
cd vlc-redesign
.\extras\juxtopposed\win64-docker.ps1     # development build (debug, asserts on)
.\extras\juxtopposed\make-release.ps1     # release: portable zip, installer, SHA256SUMS.txt (needs Inno Setup 6.7+)
```

The first build takes a while; later builds only rebuild what changed (`-Quick` skips configure). All parameters,
and instructions for the other platforms, are in
[Building from Source](https://github.com/KuchiSofts/vlc-redesign/wiki/Building-from-Source).
The interface code lives in [`modules/gui/qt`](modules/gui/qt).

</details>

## Built on VLC

VLC Redesign is the interface; everything underneath is **[VLC](https://www.videolan.org/)**, the free, open-source
media player and engine made by the VideoLAN team and a community of volunteers. Thank you to all of them.

- VLC's own project and README: [code.videolan.org/videolan/vlc](https://code.videolan.org/videolan/vlc)
- This repository is a fork of VLC's 4.0 development branch, forked on 2026-10-12. Upstream fixes are merged
  regularly: a weekly GitHub Action attempts the merge and opens a pull request, or an issue listing the conflicts.
- Project documents (platforms, translating, the plan) are in [docs/](docs/).
