# Getting help

VLC Redesign is a community project maintained in spare time. These are the best places to get help, fastest first.

| You want to… | Go to |
|---|---|
| Learn how something works | The [wiki](https://github.com/KuchiSofts/vlc-redesign/wiki): install and update, casting, subtitles, shortcuts, languages |
| Ask a question | [Discussions → Q&A](https://github.com/KuchiSofts/vlc-redesign/discussions/categories/q-a) |
| Share an idea to talk it over | [Discussions → Ideas](https://github.com/KuchiSofts/vlc-redesign/discussions/categories/ideas) |
| Show a theme, a setup or a screenshot | [Discussions → Show and tell](https://github.com/KuchiSofts/vlc-redesign/discussions/categories/show-and-tell) |
| Report a bug or ask for a feature | [A new issue](https://github.com/KuchiSofts/vlc-redesign/issues/new/choose) (pick the form that fits) |
| Help translate | [Weblate](https://hosted.weblate.org/engage/vlc-redesign/) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md); never in a public issue |

Before asking, please:

1. Update to the [latest release](https://github.com/KuchiSofts/vlc-redesign/releases/latest): the problem may
   already be fixed (see the [changelog](CHANGELOG.md)).
2. Search the [issues](https://github.com/KuchiSofts/vlc-redesign/issues?q=is%3Aissue) and
   [discussions](https://github.com/KuchiSofts/vlc-redesign/discussions).
3. Say which version you use (*⋯ menu → About VLC*), your system, and what you did.

## Not covered here

- **The official VLC media player** (playback in the official app, VLC for Android or iOS): ask
  [VideoLAN](https://www.videolan.org/support/).
- **The design itself:** the interface follows [Juxtopposed's design](https://www.youtube.com/watch?v=ERFeOgqk324);
  a difference from it is welcome as a *Design mismatch* issue.
- **Content:** this project provides no films, music or TV channels, and gives no help with content you don't have the
  right to watch.
