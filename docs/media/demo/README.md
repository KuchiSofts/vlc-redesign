# Demo clips of VLC Redesign 0.4.0

Short clips of every program and main feature, for the README, the release notes and the wiki
([Feature tour](https://github.com/KuchiSofts/vlc-redesign/wiki/Feature-Tour)). Each one is the real app, the
0.4.0 build, recorded frame by frame from its window with a drawn pointer (the clicks, wheel turns and keys shown in
the corner are the input the app got). Each GIF has an MP4 of the same clip next to it, in better quality.

Interface design by [Juxtopposed](https://www.youtube.com/@juxtopposed) (the
["VLC Redesign (Community)"](https://www.figma.com/community/file/1691465999134370980) Figma file, CC BY 4.0).

Media in the clips: the Blender open movies *Sintel*, *Big Buck Bunny*, *Elephants Dream*, *Tears of Steel* and
*Caminandes* (CC BY), music by Kevin MacLeod (incompetech.com, CC BY 4.0), the public, free Pluto TV channel list of
the Live TV catalog, and a test Chromecast that runs on the recording PC (no real device). The subtitles of *Sintel*
in Hebrew, Arabic and Japanese were written for these clips.
