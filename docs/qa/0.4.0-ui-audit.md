Cause: Qt 6 keeps a `url` property as written and resolves it through the URL interceptor only when the image
loads; `QQuickImageBase` decides from the written URL whether the image is scalable. The icons were named
`.../default.png` (the interceptor sends the `.svg`), so `devicePixelRatio` stayed 1 and the SVG was drawn at its
100 % size, then stretched. 225 names in 91 QML files now end in `.svg` (the interceptor took both). 🟡 Left: at
125 and 150 % the icon item lands on fractional device pixels (its logical position × 1.25 / 1.5), which softens the
edges; snapping needs the item's scene position.
