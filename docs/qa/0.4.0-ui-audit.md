# 0.4.0 desktop interface audit

The owner's four reports first, then every window, dialog, menu, panel and settings page of the inventory
([wiki](../wiki/Home.md), `Settings-*.md`), in the dark and light themes, left to right (English) and right to left
(Hebrew). Windows 11, the `feature/qa-ui` build, a test copy with its own portable profile, silent (`--aout=afile`),
driven by posted input on a hidden desktop; captures with `PrintWindow`. 2026-10-29.

Status: ✅ checked and right · 🔧 fixed here (commit) · 🟡 open, noted · ⬜ not checked (why).
