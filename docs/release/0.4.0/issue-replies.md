# 0.4.0: replies to the issues (drafts, posted at the upload)

Each reply is posted on its issue when 0.4.0 is published, with the release link, and the issue is closed.

## #10 Highlight Button when click on them

Thanks for both ideas, they are in 0.4.0: <release link>

- **Buttons show when they are open.** Settings, Languages and tracks (subtitles), Chapters, Bookmarks, Cast,
  Effects, Zoom, the menu and the other buttons of the player light up in the accent colour while their panel or
  menu is open, the same way a toggle that is on looks. The Android app does the same.
- **Ctrl + mouse wheel over the video changes the subtitle size** again, as in classic VLC, instead of zooming the
  interface: 10 % per step near 100 %, then 25 %, from 25 % to 500 %, with a short "Subtitle size 120%" message.
  Ctrl+0 goes back to 100 %. Over the library and the rest of the window Ctrl + wheel still zooms the interface.
  Both can be changed in Settings › Keyboard Shortcuts (*Scale up/down subtitles text* and *Zoom the interface
  in/out*). The subtitles panel also has the size, and ASS/SSA subtitles follow it too.

If something does not look right, please reopen this issue.
