# Keyboard shortcuts

VLC Redesign has two kinds of keys:

- **VLC's shortcuts** (play, seek, volume, subtitles...). Every one of them can be changed, and each can also have a
  *global* key that works from any program. They are listed below in the groups and with the names of the
  **Keyboard Shortcuts** window.
- **The keys of the interface** (open a file, open Settings, show the queue...). They belong to the window and are
  fixed.

The tables give the defaults of VLC Redesign on Windows. Where an action has several keys, any of them works.

> **Changed from VLC:** <kbd>L</kbd> shows the library next to the video (VLC's *Normal/Loop/Repeat* moved to
> <kbd>Shift</kbd>+<kbd>L</kbd>), <kbd>Q</kbd> shows the queue, <kbd>&lt;</kbd> and <kbd>&gt;</kbd> were added to
> *Previous* / *Next*, and <kbd>,</kbd> and <kbd>.</kbd> to *Previous frame* / *Next frame*, as the first-run setup
> teaches them.

## The keys of the first-run setup

The last step of the first-run setup shows these twelve. It reads the keys in use, so a key you changed shows there
as you set it.

| Action | Key |
|---|---|
| Play / Pause | <kbd>Space</kbd> |
| Seek backward / forward | <kbd>Left</kbd> / <kbd>Right</kbd> |
| Previous / next item | <kbd>&lt;</kbd> / <kbd>&gt;</kbd> |
| Previous / next frame | <kbd>,</kbd> / <kbd>.</kbd> |
| Cycle subtitle track | <kbd>V</kbd> |
| Cycle audio track | <kbd>B</kbd> |
| Toggle fullscreen | <kbd>F</kbd> |
| Increase / decrease volume | <kbd>Up</kbd> / <kbd>Down</kbd> |
| Show / hide queue | <kbd>Q</kbd> (<kbd>Ctrl</kbd>+<kbd>L</kbd> when a VLC shortcut takes <kbd>Q</kbd>) |
| Show / hide file browser (the library next to the video) | <kbd>L</kbd> |
| Take a snapshot | <kbd>Shift</kbd>+<kbd>S</kbd> |
| Record | <kbd>Shift</kbd>+<kbd>R</kbd> |

**Good to know**

- <kbd>Left</kbd>, <kbd>Right</kbd>, <kbd>Up</kbd> and <kbd>Down</kbd> are VLC's *navigation* keys. In a DVD or
  Blu-ray menu they move in the menu; in a 360° video they turn the view; otherwise <kbd>Left</kbd> /
  <kbd>Right</kbd> seek by the *short jump* (10 seconds by default) and <kbd>Up</kbd> / <kbd>Down</kbd> change the
  volume.
- <kbd>Q</kbd> and <kbd>L</kbd> work only while no VLC shortcut uses them. Give <kbd>L</kbd> to a VLC action and the
  library key stops; the queue still has <kbd>Ctrl</kbd>+<kbd>L</kbd>. <kbd>Q</kbd> also opens the queue from the
  library; <kbd>L</kbd> works in the player only.
- In the library, the arrow keys move between the cards and rows; VLC's shortcuts take over in the player.

*Scale up / down subtitles text* works with the pointer over the video (since 0.4.0): 25 % to 500 %, with a short
*Subtitle size* message. Elsewhere in the window the same turn of the wheel is *Zoom the interface in / out* (below).
A shortcut can take a turn of the wheel with <kbd>Ctrl</kbd>, <kbd>Alt</kbd> or <kbd>Shift</kbd>.

How the sync keys work: press <kbd>Shift</kbd>+<kbd>H</kbd> when you hear a line, <kbd>Shift</kbd>+<kbd>J</kbd> when
its text shows, then <kbd>Shift</kbd>+<kbd>K</kbd> to move the subtitles by the gap between the two. The
*Subtitle timing* buttons of the languages and tracks panel do the same with the mouse: see
[Subtitles](Subtitles#subtitle-timing-sync-timeline).

### Keys that two lists share

Some interface keys are also defaults of VLC actions. The window's own key is handled first, so in practice:

| Key | Interface | VLC action that loses it |
|---|---|---|
| <kbd>F1</kbd> | Help | Go to play queue bookmark 1 |
| <kbd>F10</kbd> | Menu bar | Go to play queue bookmark 10 |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Tenth media played last (with the media library) | Reset subtitles text scale |

To keep the VLC action, give it another key in Keyboard Shortcuts (for example <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>0</kbd>
for *Reset subtitles text scale*). The **Reset** button of the subtitle size, in the languages and tracks panel, also
resets the size.

## Change a shortcut

1. Open **⋯ → Keyboard Shortcuts**, or **⋯ → Settings → Controls → Keyboard Shortcuts → Edit Keyboard Shortcuts**.
2. Find the action: the list is grouped (Basic, Playback, Audio, Video, Subtitles, Navigation), or type in
   **Search Keyboard Shortcuts...** at the top. The list next to the search chooses where to look: *All Fields*,
   *Action*, *Hotkey* or *Global Hotkey*.
3. Click the **Hotkey** field (works while VLC Redesign has the focus) or the **Global Hotkey** field (works from any
   program; empty by default). The window asks *Press a key combination to add to …* (*Esc cancels*).
4. Press the keys. An action can have several keys; each shows apart in the field.
5. **Save**. The keys work at once, without a restart.

| To | Do this |
|---|---|
| Remove a key | Click the cross after it. The cross shows while the field is under the pointer or has the focus. |
| Take a key from another action | Press it anyway: the window asks *This key is assigned to … Replace that assignment?*. **Replace** moves the key here. |
| Drop your changes | Close the window without saving. |
| Go back to the defaults | **⋯ → Settings → Controls**, *Reset all shortcuts*, **Reset**: *Reset all shortcuts?* — "Local and global shortcuts will return to VLC defaults when you save. Cancel keeps your current settings." |

**Good to know**

- While a panel or a dialog of the interface is open (Languages and tracks, Effects, VLC Settings, HDR, the sleep
  timer, Customize Player, Settings, Keyboard Shortcuts, the first-run setup...), the keys go to it: VLC's
  shortcuts and the interface keys wait until it closes. <kbd>Space</kbd> does not pause while the languages and
  tracks panel is open, for example; <kbd>Esc</kbd> closes the panel first.
- The search of Settings finds shortcuts too: type an action's name in **Settings** and its keys show under
  *Keyboard Shortcuts*; a click on one opens the Keyboard Shortcuts window on it.
- Some keys cannot be used by VLC (the window says *This key combination cannot be used by VLC.*).
- The keys are part of the settings a player profile keeps: switching profile can bring other keys. See
  [Customize the player](Customize-the-Player#profiles).
- The right-click menu and the ⋯ menu show the keys in use, including the ones you set.
- The mouse wheel and clicks on the video are set in [Settings: Controls](Settings-Controls); see
  [The player](The-Player#mouse-on-the-video).
