# Keyboard shortcuts

Every key of VLC can be changed in **Keyboard Shortcuts**. The tables below are the defaults of VLC Redesign on
Windows: VLC's own shortcuts first, in the groups of the Keyboard Shortcuts window, then the keys of the interface.

> **Changed from VLC:** <kbd>L</kbd> opens the library (*Normal/Loop/Repeat* moved to <kbd>Shift</kbd>+<kbd>L</kbd>),
> <kbd>Q</kbd> opens the queue, and <kbd>&lt;</kbd> <kbd>&gt;</kbd> (previous / next) and <kbd>,</kbd> <kbd>.</kbd>
> (previous / next frame) were added.

## The keys of the design

The ones the first-run setup shows:

| Action | Key |
|---|---|
| Play / Pause | <kbd>Space</kbd> |
| Seek backward / forward | <kbd>Left</kbd> / <kbd>Right</kbd> |
| Previous / next item | <kbd>&lt;</kbd> / <kbd>&gt;</kbd> |
| Previous / next frame | <kbd>,</kbd> / <kbd>.</kbd> |
| Cycle subtitle track | <kbd>V</kbd> |
| Cycle audio track | <kbd>B</kbd> |
| Toggle fullscreen | <kbd>F</kbd> |
| Increase / decrease volume | <kbd>Up</kbd> / <kbd>Down</kbd> |
| Show / hide queue | <kbd>Q</kbd> |
| Show / hide file browser (the library) | <kbd>L</kbd> |
| Take a snapshot | <kbd>Shift</kbd>+<kbd>S</kbd> |
| Record | <kbd>Shift</kbd>+<kbd>R</kbd> |

<kbd>Left</kbd>, <kbd>Right</kbd>, <kbd>Up</kbd> and <kbd>Down</kbd> are VLC's navigation keys: in a disc menu they move
in the menu, in a 360° video they turn the view, and otherwise they seek by the *short jump* (10 seconds) and change
the volume. <kbd>Q</kbd> and <kbd>L</kbd> work only while no VLC shortcut uses them.

## Change a shortcut

Open **⋯ → Keyboard Shortcuts**, or **Settings → Controls → Keyboard Shortcuts → Edit Keyboard Shortcuts**.

The window lists every action in its group (Basic, Playback, Audio, Video, Subtitles, Navigation) with two fields:
**Hotkey** (works while VLC Redesign has the focus) and **Global Hotkey** (works from any program; none by default).

- **Search**: *Search Keyboard Shortcuts...* at the top, and the list next to it chooses where to look: *All
  Fields*, *Action*, *Hotkey* or *Global Hotkey*. The search of Settings finds shortcuts too and opens the window on
  them.
- **Add a key**: click a field (*Press to add a key*), then press the keys (*Press a key combination to add to …
  (Esc cancels)*). An action can have several keys, each shown apart. When the key belongs to another action, the
  window asks *This key is assigned to … Replace that assignment?*: **Replace** moves it here.
- **Remove a key**: the cross after it, shown while the field is under the pointer or has the focus.
- **Save** keeps the changes and they work at once, without a restart. Closing the window without saving drops
  them.
- **Reset all shortcuts** (*Settings → Controls*, button **Reset**): *Reset all shortcuts?* — *"Local and global
  shortcuts will return to VLC defaults when you save. Cancel keeps your current settings."*

The shortcuts are part of the settings a player profile keeps (see [Customize the player](Customize-the-Player#profiles)).
The right-click menu and the ⋯ menu show the keys you set.
