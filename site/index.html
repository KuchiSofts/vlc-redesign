Interface designed by Juxtopposed

Every screen of this interface comes from Juxtopposed's VLC Redesign (Community) Figma file, licensed under CC BY 4.0. This project turns that design into working software: it was implemented in Qt/QML inside VLC 4, its icons were redrawn, and some layouts were adapted to VLC's features and to window sizes the design doesn't cover. Juxtopposed does not endorse this project.
